## 2. Supabase RLS(Row Level Security) 정책

### 검증 항목
- 모든 테이블에 RLS 활성화 여부
- 적절한 POLICY 정의 여부

### 검증 결과

README.md에 명시된 SQL 기준:

| 테이블 | RLS 활성화 | 읽기 정책 | 쓰기 정책 |
|--------|------------|-----------|-----------|
| `crypto_news` | ✅ ENABLE | ✅ allow_read (USING true) | ✅ allow_insert (WITH CHECK true) |
| `crypto_prices` | ✅ ENABLE | ✅ allow_read | ✅ allow_insert |
| `crypto_analysis` | ✅ ENABLE | ✅ allow_read | ✅ allow_insert |

**판정: PASS** — 모든 테이블에 RLS 정책 정의됨  
**참고**: 운영 단계에서 `allow_read`의 `USING (true)` 를 인증 조건으로 강화 권장
